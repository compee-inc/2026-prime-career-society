PRIME CAREER SOCIETY

8 : 8 PRIVATE ROTATION | MATCHING MANAGEMENT

■ 사용 순서
  1. [인원체크] 탭에서 남녀 번호별 참석 여부, 음료, 회사명, 연락처를 체크합니다.
  2. [참가자 입력] 탭에서 참가자 이름, 나이, 직업, 연락처를 입력합니다.
  3. [첫인상] 탭에서 네이버폼 결과 엑셀을 불러오거나 직접 첫인상 1~3순위를 입력하고, 받은 표 수를 메시지로 복사해 공유합니다.
  4. 각 참가자의 1순위 / 2순위 / 3순위를 드롭다운으로 선택합니다.
  5. [상호선택] 탭에서 상호 선택 관계를 실시간으로 확인합니다.
  6. [매칭계산] 탭에서 전체 최적화 매칭 추천 결과를 확인합니다.
  7. [최종결과] 탭에서 참가자별 최종 매칭 현황을 확인합니다.
  8. [운영자 검토] 탭에서 승인 및 연락처 공유 동의를 관리합니다.
■ 운영 원칙

선택 규칙

• 1인 최대 3명 선택 (1/2/3순위)
• 이성 참가자만 선택 가능
• 순서대로 입력 (1→2→3)

매칭 규칙

• 반드시 상호 선택한 경우에만 후보
• 1인 최대 2명 매칭
• 매칭 없음도 정상 결과

점수 계산

• 1순위 = 3점  2순위 = 2점  3순위 = 1점
• 쌍방 합산 → 최대 6점
• 높은 점수 조합을 우선 배정

연락처 공유

• 매칭 후 운영자 최종 승인 필수
• 양측 동의 확인 후에만 공유
• 한쪽만 거절해도 공유 불가

■ 연락처 공유 상태 코드
MATCHED — 상호선택 확인
PENDING CONSENT — 동의 확인 중
BOTH CONSENTED — 양측 동의
ONE SIDE DECLINED — 한쪽 거절
CONTACT SHARED — 공유 완료
DECLINED BY OPERATOR — 운영자 미승인
※ 입력한 모든 데이터는 브라우저에 자동 저장됩니다. (localStorage)
※ 실제 운영 시 테스트 데이터를 먼저 삭제하세요. 우측 상단 [초기화] 버튼을 사용하세요.
※ 순위 변경 즉시 모든 계산이 자동으로 갱신됩니다.
